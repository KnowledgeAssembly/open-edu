# Let's Review Adaptive Learning

Let's go over the key concepts again.

## Key Points

- **Adaptive learning** personalizes the educational path based on learner performance
- **Score-based branching** directs learners to different nodes depending on quiz results
- **Remediation** provides additional review material for challenging topics
- **Reflection** helps consolidate learning after mastering the material
