# Algebra Skill Graph

This learning experience uses mastery-based routing to help you build algebra skills step by step.

## Skills in This Lesson

- **Algebra Basics** — foundational algebra concepts
- **Algebra Advanced** — advanced algebra (unlocked by mastering basics)

## How It Works

1. Review the basics and take the **Basics Quiz**
2. Score 80% or higher to unlock the **Advanced Quiz**
3. If you need more practice, remediation will help you review
4. Pass the advanced quiz to complete the lesson

> Press **Next** to begin the basics quiz.
