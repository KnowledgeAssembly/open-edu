# Let's Review Algebra

Let's go over the key concepts again before retrying.

## Algebra Basics

- An **equation** states that two expressions are equal (e.g., x + 3 = 7)
- To solve, perform the same operation on both sides — subtract 3 from both sides to get x = 4
- **Variables** represent unknown values
- **Inverse operations** undo each other (addition/subtraction, multiplication/division)

## Algebra Advanced

- A **quadratic equation** has the form ax² + bx + c = 0
- The **quadratic formula** solves for x: x = (-b ± √(b² - 4ac)) / 2a
- **Factoring** is another method: write as (x + p)(x + q) = 0
