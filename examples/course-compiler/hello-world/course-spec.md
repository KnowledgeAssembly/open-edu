# Module 1: Getting Started

Welcome to the Hello World course. This module will introduce you to basic concepts.

## Lesson 1.1: Hello World

**Objectives:**

- Understand what "Hello World" means
- Write your first Hello World program

The "Hello World" program is a classic first step in learning any programming language.

### Activity: Reading

Read about the history of Hello World programs. The tradition started with Brian Kernighan's 1972 tutorial for the B programming language.

## Lesson 1.2: Next Steps

**Objectives:**

- Identify resources for continued learning
- Understand how to practice effectively

Now that you've written your first program, it's time to explore further. Practice regularly and build small projects to reinforce your learning.

**Glossary:**

- Hello World: A simple program that outputs "Hello, World!" to demonstrate basic syntax
- Program: A set of instructions that a computer follows
