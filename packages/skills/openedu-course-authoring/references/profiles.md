# OpenEdu Learner Profiles Reference

Schema Version: 1
Default Profile: `neurotypical`

## Profiles List

### Neurotypical (`neurotypical`)

- **Audience**: neurotypical
- **Description**: Default profile. Standard default skill behavior; base authoring layer.
- **Accessibility Tags**: none
- **Pacing**: 15–45 minutes
- **Prompt Instructions**: Adapt content for a general neurotypical learner: standard clear explanations, balanced pacing (15-45 min), and standard difficulty progression.

### Autism Spectrum (`autism`)

- **Audience**: autism
- **Description**: Autistic learners. Prioritizes predictability, visual support, literal language, and errorless learning.
- **Accessibility Tags**: sensory-friendly, predictable-structure, literal-language
- **Pacing**: 10–30 minutes
- **Prompt Instructions**: Adapt content for an autistic learner: use strict literal language (5-12 words per sentence, no idioms/metaphors), direct step-by-step instructions, one concept per activity, predictable structure, visual emphasis, and calm non-exaggerated feedback.

### School (K-12) (`school`)

- **Audience**: school
- **Description**: School-age learners (K-12). Age-graded register, curriculum-aligned objectives, grade-band-appropriate pacing.
- **Accessibility Tags**: none
- **Pacing**: 15–45 minutes
- **Prompt Instructions**: Adapt content for K-12 school learners: age-appropriate vocabulary and grade-band pacing, concrete visual examples, curriculum-aligned objectives, and direct step-by-step activity instructions.

### College / Adult (`college`)

- **Audience**: college
- **Description**: Higher-education / adult learners. Academic rigor, independence, disciplinary terminology, and deeper conceptual treatment.
- **Accessibility Tags**: none
- **Pacing**: 20–60 minutes
- **Prompt Instructions**: Adapt content for college/adult learners: formal disciplinary register, higher-order objectives (apply, analyze, evaluate), realistic case-based examples, deeper independent learning blocks (20-60 min).
