# Typography

> _"Typography gives ideas a calm and readable voice."_

---

# Introduction

Typography is the primary medium through which learners interact with
OpenEdu.

Before a learner clicks a button or watches an animation, they read.

Typography should therefore reduce effort, improve comprehension, and
create confidence.

It is a tool for understanding, not decoration.

---

# Purpose

The OpenEdu typography system exists to:

- improve readability
- support comprehension
- establish hierarchy
- reduce cognitive load
- remain accessible across devices

Good typography should feel almost invisible.

---

# Readability First

Every typographic decision should prioritize reading comfort.

Prefer:

- generous line spacing
- comfortable line lengths
- clear hierarchy
- consistent spacing

Avoid styles that make reading harder than necessary.

---

# Hierarchy

Hierarchy should communicate structure naturally.

Learners should immediately recognize:

- page titles
- section headings
- lesson content
- supporting information
- captions
- metadata

Hierarchy should emerge through scale and spacing rather than excessive
styling.

---

# Consistency

Similar content should always be presented in similar ways.

Consistent typography reduces the effort required to understand the
interface.

Predictability builds confidence.

---

# Accessibility

Typography should support:

- scalable text
- high contrast
- dyslexia-friendly layouts
- screen readers
- responsive interfaces

No learner should struggle because text is difficult to read.

---

# Calm Expression

Typography should feel:

- calm
- thoughtful
- approachable
- timeless

Avoid styles that feel loud, decorative, or distracting.

Learning should remain the focus.

---

# Implementation Independence

Typography defines communication principles rather than specific fonts
or framework styles.

Font families, scales, and tokens may vary across implementations while
preserving the same reading experience.

---

# Design Questions

Before introducing a new text style, ask:

- Does it improve readability?
- Is it necessary?
- Does it strengthen hierarchy?
- Will learners recognize it consistently?
- Does it reduce cognitive effort?

If not, simplify.

---

# Closing Thought

Learners should remember what they learned, not how the text looked.

Typography succeeds when it quietly helps ideas become understanding.
