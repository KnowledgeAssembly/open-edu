# Progressive Web App

OpenEdu is a Progressive Web App (PWA) that supports offline-first learning, installability, automatic updates, and low-bandwidth operation. The PWA layer enables learners to download courses, disconnect from the internet, and continue learning with full progress persistence.

## Architecture

```
┌─────────────────────────────────────────────────┐
│                  Learner App                     │
│  InstallPrompt · UpdatePrompt · OfflineBanner    │
│  StorageSettingsPage · DownloadedCourseList       │
├─────────────────────────────────────────────────┤
│                 React Hooks                      │
│  useInstallPrompt · useUpdatePrompt              │
│  useOnlineStatus · useStorageUsage               │
├──────────────────────┬──────────────────────────┤
│   @open-edu/pwa-core │   @open-edu/storage       │
│   Install · Update   │   IndexedDB (6 stores)    │
│   Connectivity       │   Courses · Progress      │
│   Storage Info       │   Badges · Cards           │
│                      │   Search · Preferences     │
├──────────────────────┴──────────────────────────┤
│            vite-plugin-pwa + Workbox             │
│  Service Worker · Runtime Caching · Manifest     │
└─────────────────────────────────────────────────┘
```

## Packages

| Package              | Purpose                                                                         |
| -------------------- | ------------------------------------------------------------------------------- |
| `@open-edu/pwa-core` | Framework-agnostic PWA primitives (install, update, connectivity, storage info) |
| `@open-edu/storage`  | IndexedDB persistence layer with 6 typed object stores                          |

## Service Worker

The service worker is generated by `vite-plugin-pwa` using Workbox. It handles:

- **Application shell caching** — CacheFirst for JS, CSS, fonts, icons
- **API caching** — NetworkFirst for API responses with cache fallback
- **Metadata caching** — StaleWhileRevalidate for course listings and catalog metadata
- **Offline routing** — serves cached app shell when offline

### Runtime Caching Strategies

| Resource                       | Strategy             | Purpose                                             |
| ------------------------------ | -------------------- | --------------------------------------------------- |
| Static assets (JS, CSS, fonts) | CacheFirst           | Fastest load from cache                             |
| API / metadata endpoints       | NetworkFirst         | Fresh data when online, cache fallback when offline |
| Course catalog listings        | StaleWhileRevalidate | Show cached data immediately, update in background  |

### Configuration

The PWA is configured in `apps/learner/vite.config.ts`:

```ts
VitePWA({
  registerType: 'autoUpdate',
  includeAssets: ['favicon.svg', 'icon-192.png', 'icon-512.png', 'icon-maskable.png'],
  workbox: {
    globPatterns: ['**/*.{js,css,html,svg,png,woff,woff2}'],
    runtimeCaching: [
      /* ... */
    ],
  },
});
```

## IndexedDB Storage

All learner persistence uses IndexedDB via `@open-edu/storage`. See [Storage](storage.md) for the full store reference.

| Store            | Data                                                     |
| ---------------- | -------------------------------------------------------- |
| `courses`        | Downloaded course packages (manifest, nodes, assets)     |
| `progress`       | Per-node learning progress (completed, score, timestamp) |
| `search-indexes` | Persisted MiniSearch indexes per locale                  |
| `preferences`    | User preferences (locale, theme, font size)              |
| `badges`         | Earned badge records per course                          |
| `cards`          | Knowledge Card level and unlock timestamp                |

## Components

### InstallPrompt

Displayed on the catalog page when the app is installable. Shows a banner with an "Install" button that triggers the browser's native install prompt.

- File: `apps/learner/src/components/InstallPrompt.tsx`
- Hook: `useInstallPrompt` → bridges `@open-edu/pwa-core` install detection to React

### UpdatePrompt

Displayed in the app shell when a new service worker version is detected. Shows a notification with "Update" and "Dismiss" buttons. Updates never force-reload or interrupt learning.

- File: `apps/learner/src/components/UpdatePrompt.tsx` (from `@open-edu/runtime`)
- Hook: `useUpdatePrompt` → bridges `@open-edu/pwa-core` update detection to React

### OfflineBanner

Displayed in the app shell when the device goes offline. Shows a persistent banner indicating offline mode with cached content available.

- File: `apps/learner/src/components/OfflineBanner.tsx`
- Hook: `useOnlineStatus` → wraps `onOnlineStatusChange` from `@open-edu/pwa-core`

### StorageSettingsPage

Settings page showing storage usage, a list of downloaded courses with delete buttons, and a storage usage card.

- File: `apps/learner/src/pages/StorageSettingsPage.tsx`
- Components: `StorageUsageCard`, `DownloadedCourseList`
- Hook: `useStorageUsage` → wraps `getStorageUsage` from `@open-edu/pwa-core`

## Hooks

| Hook               | Source                                           | Purpose                         |
| ------------------ | ------------------------------------------------ | ------------------------------- |
| `useInstallPrompt` | `apps/learner/src/hooks/useInstallPrompt.ts`     | Install state + prompt trigger  |

## Testing PWA

### Dev Mode

The dev server (`pnpm dev`) does **not** generate a real service worker. Use production build for full PWA testing:

```bash
pnpm --filter @open-edu/learner build
pnpm --filter @open-edu/learner preview
```

### Browser Testing

1. Open `http://localhost:4173` in Chrome or Edge
2. **Service Worker:** DevTools → Application → Service Workers
3. **Install:** DevTools → Application → Manifest (or look for install banner)
4. **Offline:** DevTools → Network → check "Offline"
5. **IndexedDB:** DevTools → Application → IndexedDB → `open-edu`

### Firefox Notes

Firefox has limited PWA support:

- No `beforeinstallprompt` event (install prompt not available)
- Service workers work but behave differently
- Use `about:debugging` → This Firefox → Service Workers to debug

### Build Verification

```bash
pnpm --filter @open-edu/learner test -- --run src/__tests__/build-output.test.ts
```

Verifies that service worker, manifest, and icons are generated in the build output.

### Accessibility Tests

9 axe-core tests across 6 PWA components:

```bash
pnpm --filter @open-edu/learner test -- --run src/__tests__/*a11y*.test.tsx
```
