# Storybook

The design system components are documented in Storybook.

## Running Storybook

```bash
pnpm storybook
```

This starts the Storybook dev server on port 6006.

## Building Static Storybook

```bash
pnpm build-storybook
```

Output goes to `packages/design-system/storybook-static/`.

## Theme Switching

Use the **Theme** dropdown in the Storybook toolbar to switch between the 4 available themes:

- **Lumina Scholastica** — Light, scholarly theme
- **Nocturnal** — Dark theme
- **Zen** — Minimalist light theme
- **Forest** — Nature-inspired light theme
