# OpenEdu Visual Rules

# Typography

Priority:

Content before decoration.

---

Display

Landing pages only

---

H1

Page title

---

H2

Major section

---

H3

Subsection

---

Body

Primary reading text

---

Caption

Supporting information

---

Label

Forms and controls

---

# Reading Experience

Maximum line length:

70–80 characters

Line height:

1.5–1.7

Paragraph spacing:

Generous

Never create dense text walls.

---

# Spacing System

Base Unit:

4px

Scale:

4
8
12
16
24
32
48
64

Prefer larger spacing.

Avoid crowded layouts.

---

# Surface Rules

Default:

Flat surfaces

Use borders before shadows.

Use shadows only when elevation matters.

---

# Border Radius

Subtle

Avoid excessive rounding.

Goal:

Professional
Friendly

Not playful.

---

# Color Usage

Color communicates meaning.

Not decoration.

Use color for:

- Status
- Progress
- Focus
- Feedback

Avoid:

- Random accents
- Rainbow dashboards

---

# Motion Rules

Purpose:

Communicate state change.

Never decorate.

Durations:

Fast:
100–150ms

Normal:
200–300ms

Slow:
300–500ms

---

# Focus States

Always visible.

Keyboard users must clearly know:

- Current focus
- Current location
- Available actions

---

# Educational Widgets

Widgets are primary learning tools.

They should:

- Feel lightweight
- Load quickly
- Work on mobile
- Support accessibility

Avoid:

- Excessive chrome
- Complex controls
- Hidden interactions

---

# Illustration Rules

Illustrations support learning.

Illustrations do not decorate empty space.

Preferred style:

- Simple
- Friendly
- Educational
- Folk-inspired
- Accessible

Avoid:

- Corporate stock illustrations
- Hyper-realistic artwork
- Decorative clutter

---

# MVP Visual Goal

If someone sees OpenEdu for 30 seconds they should think:

"This feels clear, modern, and easy to learn."

Not:

"This looks like enterprise software."

And not:

"This looks like a children's toy."
