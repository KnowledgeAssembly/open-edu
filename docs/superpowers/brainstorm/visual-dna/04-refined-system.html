Refined Visual DNA System

Three directions refined from your selections. Each element uses the circle primitive and expresses assembly, openness, and calm.

1

Open Module — Orbital Cluster

Variable satellites (2–6) clustered on one side of a dashed orbit ring. The empty space on the orbit is intentional — it says "this module is not full, there is room for more." Satellite count scales with context: 2 for badges, 3 for cards, 5 for illustrations.
Size variants — compact to illustration
Badge — 2 sats
Card — 3 sats
Illustration — 5 sats
2

Pattern Language — Assembly Flow

Single flowing dashed path connecting circle nodes. The path curves gently — never straight, suggesting exploration. Nodes vary in size and opacity to create depth. Works at any scale: dense for backgrounds, sparse for section dividers.
Density variants — background to divider
Background — dense
Card accent — medium
Section divider — minimal
3

Illustration Language — Silhouette Assembly

Proportion variation creates diversity. Each figure is a circle head atop a rounded torso — translucent, layered. Different heights, widths, and head-to-body ratios suggest different people without specifying features. No faces, no limbs — posture and proportion carry the meaning.
Figure proportions — the diversity system
Composition — a learning scene

Specification Summary

Open Module

  • Shape: Circle core + circle satellites
  • Orbit: Dashed ring, always visible
  • Satellites: 2–6, clustered with gaps
  • Incompleteness: Empty orbit space
  • Colors: primary core, primary-light sats
  • Sizes: sm (80px), md (120px), lg (180px)

Assembly Flow

  • Path: Single dashed curve
  • Nodes: Circles, varied size/opacity
  • Density: Dense (bg), medium, minimal
  • Colors: primary nodes, accent accents
  • Stroke: 1.5px, dashed 8/5
  • Use: Backgrounds, dividers, cards

Silhouette Assembly

  • Parts: Circle head + rounded torso
  • Diversity: Proportion variation
  • Heights: Tall, medium, short
  • Widths: Standard, wide, narrow
  • Colors: 5 palettes (primary→green)
  • Transparency: Head 70%, torso 25%

These three elements form the Visual DNA of OpenEdu. They share the circle primitive and express assembly, openness, and calm.
