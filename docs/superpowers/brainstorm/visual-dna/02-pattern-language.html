Stage 3 — Visual DNA

Pattern Language — Visual Textures

How should repeated modules create background textures, empty states, loading animations, and reward visuals? The pattern must emerge naturally from the Open Module.

Philosophy: "One module is simple; many modules create beauty." Patterns should feel calm, not busy. They should reduce cognitive load, not increase it. Silence is part of the interface.
Use cases:
Background textures
Empty states
Loading animations
Reward celebrations
Section dividers
Option A

Dot Grid

Regular grid of circles with varying opacity. Creates a calm, structured texture. The uniform spacing conveys order; the opacity variation adds depth without noise. Feels like graph paper made of light.

structured calm easy to animate
Option B

Organic Scatter

Circles scattered with slight random offsets in position and size. Feels natural, like particles floating in space. The randomness is constrained — never chaotic, always calm. Good for empty states and loading.

organic gentle harder to grid
Option C

Concentric Waves

Ripple patterns expanding from points. A core circle emits rings that fade outward. Multiple ripple sources can overlap. Directly expresses growth and discovery — knowledge radiating outward.

growth discovery natural animation
Option D

Assembly Flow

Circles connected by flowing dashed paths. Shows the journey of assembly — ideas connecting along a path. The paths are never straight; they curve gently, suggesting exploration over rigid structure.

journey connection storytelling
