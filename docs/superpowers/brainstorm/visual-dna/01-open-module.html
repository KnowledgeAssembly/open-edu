Stage 3 — Visual DNA

Open Module — Visual Expression

How should a single learning module look? It must emerge from the geometric primitive (circle), suggest that another connection is always possible, and create beauty through repetition.

Philosophy: "A module is never complete — it should always suggest that another connection is possible." One module is simple; many modules create beauty. Every visual pattern emerges naturally from repeated modules. Assembly over hierarchy.
Option A

Orbital Cluster

A central circle surrounded by satellite circles on an orbit path. Suggests a core concept with connected sub-topics. The dashed orbit implies potential for more satellites — the module is never complete.

assembly growth scales well
Option B

Stacked Layers

Nested rounded rectangles with increasing opacity toward the center. Represents depth — a module contains layers of understanding. The outermost layer is always "open" (lighter, incomplete feeling).

depth progressive contained
Option C

Connected Nodes

Circles of varying sizes connected by dashed lines. A small network graph. Directly expresses "assembly" — modules connect to form understanding. Dashed lines suggest connections yet to be made.

network connection most literal
Option D

Overlapping Circles

Three overlapping circles with transparency, creating a shared intersection. The overlap zones are darker — meaning emerges from the intersection of ideas. A single dot at the center marks the core concept.

intersection emergence minimal
