Component Composition

<CourseCardWithModule progress={progress} badgeCount={badgeCount}>
  <CourseCard manifest={manifest} onStart={onStart} />
</CourseCardWithModule>

The pattern component wraps the runtime CourseCard and adds the Open Module indicator based on progress state. The runtime component stays generic.
