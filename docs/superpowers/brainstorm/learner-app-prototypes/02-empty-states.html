Design Principles

  • Open Module always shows 2 satellites (incomplete state) — room for more
  • SilhouetteGroup humanizes the empty experience — not alone, but together
  • Action button provides clear next step — don't leave users stranded
  • Translucent colors create calm, non-aggressive visual tone
