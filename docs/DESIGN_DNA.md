# OpenEdu Design DNA

## Purpose

OpenEdu exists to make learning calm, accessible, engaging, and open.

The product should feel like:

- A learning companion
- A thoughtful workspace
- A modern educational platform

It should never feel like:

- Enterprise software
- A corporate dashboard
- A social media application
- A gamified addiction machine

---

# Core Principles

## 1. Learning First

Every interface decision must improve learning.

Question:

"Does this help the learner understand, focus, remember, or progress?"

If not, remove it.

---

## 2. Calm by Default

The interface should reduce cognitive load.

Avoid:

- Visual clutter
- Excessive notifications
- Competing focal points
- Aggressive animations

Prefer:

- Whitespace
- Clear hierarchy
- Predictable behavior
- Consistent patterns

---

## 3. Accessibility is a Feature

Accessibility is not compliance work.

Accessibility is product quality.

Requirements:

- Keyboard navigation
- Screen reader support
- High contrast support
- Reduced motion support
- Autism-friendly mode

---

## 4. Progressive Complexity

Begin simple.

Reveal complexity when needed.

Students should never face an overwhelming screen.

---

## 5. Open and Portable

Users own their content.

Avoid patterns that lock users into the platform.

---

# Product Inspirations

## Linear

Borrow:

- Navigation
- Layout density
- Workspace organization
- Keyboard-first interactions

Do not borrow:

- Developer-centric language
- Issue tracking metaphors

---

## Notion

Borrow:

- Reading experience
- Typography hierarchy
- Content presentation
- Information architecture

Do not borrow:

- Infinite canvas complexity

---

## Khan Academy

Borrow:

- Learning progression
- Lesson flow
- Educational clarity
- Student motivation

Do not borrow:

- Visual styling

---

# Emotional Tone

The product should feel:

- Calm
- Helpful
- Trustworthy
- Curious
- Encouraging

The product should not feel:

- Competitive
- Noisy
- Corporate
- Distracting
- Overly playful

---

# Design Anti-Patterns

Avoid:

- Glassmorphism
- Heavy gradients
- Neon colors
- Excessive shadows
- Card-in-card nesting
- Overuse of modals
- Infinite scrolling
- Notification overload

---

# Success Criteria

A learner should be able to:

1. Find what they need.
2. Understand where they are.
3. Focus on one task.
4. Make steady progress.
5. Leave without feeling overwhelmed.
